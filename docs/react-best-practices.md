# React Best Practices (외부 레퍼런스)

이 프로젝트에서 React 코드 스타일/패턴을 정리할 때 참고할 “규칙 모음” 레퍼런스입니다.

- 원문: [vercel-labs/agent-skills — react-best-practices](https://github.com/vercel-labs/agent-skills/tree/main/skills/react-best-practices)

## 이 레포에서 어떻게 쓰면 좋을까?

- 새로운 컴포넌트/훅/데이터 패칭 패턴을 추가할 때, 여기 규칙을 기준으로 **일관성 있게** 구현합니다.
- “학습 페이지” 같은 데모를 만들 때도, **좋은/나쁜 예시**를 구분해두고 규칙 형태로 축적하면 유지보수가 쉬워집니다.

## 포함 내용(원문 기준)

- `rules/`: 규칙 파일(영역별 prefix로 분류)
- `AGENTS.md`: 규칙을 합쳐서 만든 컴파일 결과물
- `test-cases.json`: LLM 평가용 테스트 케이스(생성물)
